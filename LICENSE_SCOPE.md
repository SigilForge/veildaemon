# License Scope & Component Matrix

VeilDaemon uses a dual-layer licensing architecture harmonized with the **SigilForge Rights Framework (SFR)**.

## Dual-Layer Architecture

VeilDaemon separates open core software logic from proprietary rights infrastructure, assets, and brand identity:

1. **Layer 1 (Core Source Code)**: Governed by the Apache License, Version 2.0.
2. **Layer 2 (Rights Infrastructure & Assets)**: Governed by the SigilForge Rights Framework (SFR) and All Rights Reserved defaults.

## Component Matrix

| Component | License / Governing Framework | Scope & Details |

| **Core Documentation** | Apache License 2.0 / SFR | Technical system documentation under Apache 2.0; narrative, lore, and brand guides under SFR. |
| **Third-Party Dependencies** | Third-Party Open Source | Governed by their respective open-source licenses. |
