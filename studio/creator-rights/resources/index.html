Creator Ecosystem & Standards Directory

Creator Toolkit & Related Resources

Creator Rights Records (CRR) complement existing legal registries, open licensing standards, and global distribution channels. Use this directory to navigate complementary copyright offices, persistent identifiers, license databases, and technical specifications.

Non-Affiliation Notice: The third-party registries, standards organizations, and services listed below are provided for creator reference to illustrate ecosystem integration. SigilForge Rights is an independent publication record and is not endorsed by or affiliated with government copyright offices or third-party platforms unless specified.

Copyright & Registration Legal

Official registration authorities and international intellectual property organizations for statutory legal backing.

  • U.S. Copyright Office (eCO) ↗ Official United States government copyright registration portal for statutory protection and legal remedies.
  • World Intellectual Property Organization (WIPO) ↗ UN agency providing international IP treaties, copyright information, and global IP protection frameworks.

Creative & Open Licenses Licensing

Standardized human-readable and machine-actionable licensing terms for public, open-source, and commercial distribution.

  • Creative Commons (CC) ↗ Standardized public licenses (CC BY, CC BY-NC, CC0) for granting flexible usage permissions.
  • SPDX License List ↗ Standard identifier list for open-source software, documentation, and data licenses.
  • Open Source Initiative (OSI) ↗ Steward of the Open Source Definition and official reviewer of open-source license compliance.

Persistent Identifiers Identifiers

Global registration agencies for assigning unique, persistent identifiers to books, research, and creator identities.

  • International ISBN Agency ↗ Official international coordinator for International Standard Book Numbers (ISBN) for print & eBooks.
  • International DOI Foundation ↗ Digital Object Identifiers providing persistent links for research, scholarly papers, and media objects.
  • ORCID ↗ Unique persistent identifier distinguishing individual researchers, scholars, and academic authors.
  • ISNI (International Standard Name Identifier) ↗ ISO standard identifier for uniquely identifying public identities of creators and contributors.

Source & Code Provenance Code

Public version control platforms for hosting source code, commit history, and release tags.

  • GitHub ↗ Git repository hosting platform for tracking commit hashes, release assets, and open-source licenses.
  • GitLab ↗ DevOps and Git version control platform for self-hosted and cloud repository management.

Publishing & Distribution Channels

Distribution platforms for reaching readers, players, and buyers across print, digital, and game marketplaces.

  • IngramSpark ↗ Global self-publishing platform for print-on-demand books and commercial eBook distribution.
  • Draft2Digital ↗ Aggregated eBook self-publishing platform distributing to major global digital storefronts.
  • itch.io ↗ Creator-first marketplace for independent video games, game assets, table-top RPGs, and digital books.
  • Steamworks ↗ Valve platform for PC game publishing, release management, and digital distribution.

Technical Specifications Standards

Open standards used by SigilForge for verification cryptographic hashing and machine-readable metadata schema.

  • SHA-256 Cryptographic Standard (FIPS 180-4) ↗ NIST standard defining Secure Hash Algorithm 256 for deterministic file fingerprinting.
  • JSON Schema ↗ Standardized vocabulary for validating and structuring machine-readable JSON rights metadata.
