# GEMINI.md

Read `AGENTS.md`, `ARCHITECTURE.md`, and `SECURITY.md` before editing; those local rules apply to Gemini in full.

The shared SigilForge Agent Brain contract is `docs/agent-brain/AGENT_CONTRACT.md` **in the separate VeilForge repository**. When `veil` is available, run `veil brain where`, read that contract, run `veil brain query "<what the task touches>"`, and open the cited files. After changes affecting Brain notes, update the notes/sources/decisions as applicable and run `veil brain index`.

Without `veil`, follow the tracked repository instructions directly. Never copy private VeilForge contracts or machine-local information into this public repository.
